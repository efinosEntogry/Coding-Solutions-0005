# Coding-Solutions-0005
Movie Ticket Booking System

Write a program that:
• Displays 3 movie options with different ticket prices (e.g.,
Movie A: $8, Movie B: $10, Movie C: $12).
• Allows the user to select a movie and enter the number of
tickets.
• Calculates and displays the total cost.
• Uses a switch-case for movie selection.
• Uses a do-while loop for multiple bookings.
• Uses a function to calculate the total price.

Example:
Input: Select Movie B, Tickets: 3
Output: Total Cost: $30

Input: Select Movie C, Tickets: 2
Output: Total Cost: $24
